# Go implementation

**Version:** 2.0.1  
**Default run mode:** `SNYK_CLI`

This directory contains the standalone Go implementation of the Snyk SBOM →
ServiceNow utility. It compiles to a static executable with no Python, Go
toolchain, or package dependency on the target host.

See the repository-root [`README.md`](../README.md) for the complete
configuration, Jenkins, and customer deployment documentation.

## Build and verify

Go 1.22 or newer is required to build:

```bash
cd go
make check
make build
./bin/snyk-sbom-to-servicenow --version
```

Build Linux, macOS, and Windows release binaries for amd64/arm64:

```bash
make cross-compile VERSION=2.0.1
```

Artifacts are written to `go/dist/`.

## Run

The binary loads `.env` from the current working directory. `SNYK_CLI` is the
default, so an SBOM file path is required unless API mode is selected explicitly.

```bash
# Default: upload a file generated by the native Snyk CLI
./bin/snyk-sbom-to-servicenow --sbom-file-path ./sbom.json

# Snyk REST API mode
RUN_MODE=SNYK_API ./bin/snyk-sbom-to-servicenow
```

Use `--version` for the embedded semantic version and `--help` for flags.

## Source layout

```text
cmd/snyk-sbom-to-servicenow/  executable entrypoint
internal/apperr/              typed errors and exit codes
internal/climode/             SNYK_CLI orchestration
internal/config/              .env loading, defaults, validation
internal/httpx/               HTTP/TLS wrapper
internal/logging/             leveled logging
internal/redact/              secret redaction
internal/sbomfile/            timestamped file persistence
internal/scope/               API scope orchestration and summary
internal/servicenow/          ServiceNow upload client
internal/snyk/                Snyk SBOM and discovery clients
```
