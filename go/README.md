# Go implementation

This directory contains the standalone Go implementation of the Snyk SBOM →
ServiceNow utility. It mirrors the behavior documented by the repository's
OpenSpec capabilities and the legacy Python implementation, while producing a
single binary with no Python or Go runtime dependency on the target host.

## Requirements

- Go 1.22 or newer (build/test only)
- Network access to Snyk and ServiceNow at runtime

## Build and verify

```bash
cd go
make check
make build
./bin/snyk-sbom-to-servicenow --version
```

Build release binaries for Linux, macOS, and Windows (amd64/arm64):

```bash
make cross-compile VERSION=1.0.0
```

Artifacts are written to `go/dist/`.

## Run

The Go binary reads the same `.env` file and environment variables as the
Python implementation. Run it from the directory containing `.env`.

```bash
# Snyk REST API mode
./bin/snyk-sbom-to-servicenow

# Upload a file generated by the Snyk CLI
RUN_MODE=SNYK_CLI ./bin/snyk-sbom-to-servicenow \
  --sbom-file-path ./sbom.json
```

Use `--version` for the embedded semantic version and `--help` for flags.

## Source layout

```text
cmd/snyk-sbom-to-servicenow/  executable entrypoint
internal/apperr/              typed errors and exit codes
internal/climode/             SNYK_CLI orchestration
internal/config/              .env loading, defaults, validation
internal/httpx/               HTTP/TLS wrapper
internal/logging/             leveled logging
internal/redact/              secret redaction
internal/sbomfile/            timestamped file persistence
internal/scope/               API scope orchestration and summary
internal/servicenow/          ServiceNow upload client
internal/snyk/                Snyk SBOM and discovery clients
```
